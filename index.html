💡 사용 팁 Encode는 일반 텍스트를 변환할 때, Decode는 이미 변환된 문자열을 원래 형태로 되돌릴 때 사용합니다. 자동 인식을 이용하면 형식을 직접 선택하지 않아도 됩니다.

🔍 자동 인식

입력된 문자열을 분석하여 Base64, URL Encoding, HTML Entity, Hex, Binary, Decimal, Octal, Unicode Escape, Morse 등의 가능성이 높은 형식을 찾아냅니다.

대기 중 입력 내용을 넣으면 자동으로 형식을 분석할 수 있습니다.
